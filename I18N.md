# Internationalization

## Approach
Vanilla static SPA (no build step) so GitHub Pages can keep deploying the repo root.

## Routing
**Path-prefix locales** on GitHub Pages:
- `/` and `/en/` → English
- `/sl/`, `/de/`, … → other languages
- `/sl/privacy`, `/de/terms` → legal pages

`404.html` captures deep links on Pages, stores the path in `sessionStorage`, and redirects to `index.html`. `app.js` restores the path via `history.replaceState`.

## Locales
`locales/{code}.json` — one file per language (UI + Privacy + Terms markdown).

## Language UX
- Detect `navigator.language` (and `languages[]`), fall back to `en`
- Persist choice in `localStorage` key `m4th:lang`
- Switcher shows native names + flags (never translated)
- Sets `<html lang>` and document title / meta description per locale

## Preview locally

cd m4th3m4t1c4-site
python3 -m http.server 8080
# open http://localhost:8080/ and http://localhost:8080/sl/
